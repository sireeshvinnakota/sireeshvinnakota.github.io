Recall: Symmetric groups

Definition

Let $[n] = {1, \dots, n}$, and consider a permutation $\sigma : [n] \longrightarrow [n]$ (one-to-one and onto). The collection of all such, together w/ composition, form the symmetric group $S_n$.

We can represent these in three ways:

  1. Cycle notation.
  2. Transpositions: for a cycle $(a_1\ \cdots\ a_n)$ we can write $$(a_1\ \cdots\ a_n) = (a_1\ a_n) \cdots (a_1\ a_3)(a_1\ a_2).$$
  3. Disjoint cycles. (This was a theorem.)
Question

What's the order of an element?

Start w/ the building blocks: $$|(a_1\ \cdots\ a_n)| = n.$$

What if we have two? $$(a_1\ \cdots\ a_m)(b_1\ \cdots\ b_n)$$ First is $\mathbb{1}$ every $m$, second every $n$. Thus we have:

Fact

A cycle of type $(n_1, \dots, n_m)$ has order $\operatorname{lcm}(n_1, \dots, n_m)$.

Example

Show that $A_{10}$ contains an element of order $15$.

Proof

Note that order $15 = \operatorname{lcm}(3, 5)$. Are these in $A_{10}$?

Problem

Does $A_8$ contain an element of order $26$?

Proof

No. These are either $26$-cycles or of type $(2, 13)$. Can't happen.

Problem

What are all the cycle types in $A_4$?

Solution
  • $(1, 1, 1, 1)$
  • $(2, 2)$
  • $(3)$

Dihedral Groups

Consider $n > 0$ a positive integer, and construct a regular $n$-gon. We can say vertices are at $$\alpha_j = \left(e^{2\pi i / n}\right)^j.$$

Claim

There are $2n$ possible symmetries of the $n$-gon.

Why?

There are $n$ choices for the first vertex, and for a given vertex $k$, moving CCW returns either $k+1$ or $k-1$.

Definition

The set $D_n = { r, s, rs, \dots }$ is called the dihedral group under composition.

Proposition

Define $r$ = CCW rotation by $2\pi/n$ rad, $s$ = flipping/reflecting across the $x$-axis. Then $D_n = \langle r, s \rangle$, with $r^n = 1$, $s^2 = 1$, and $srs = r^{-1}$.

Is $D_n$ abelian?

Let $n = 3$, consider $r, s$. Triangle vertices are labeled $1, 2, 3$ and we track the labels at the angles $0°, 120°, 240°$.

Question

How do we generalize this argument?

Notice from above that $$srs = r^{-1} \iff sr = r^{-1}s.$$
